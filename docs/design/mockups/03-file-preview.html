Counts are taken at the daemon listener on 127.0.0.1:7420 and at the Tailscale HTTPS front end. Latency runs from first byte to last byte of each request.

Sessions group by paired device. Dropped connections leave the latency figures but stay in the request count.

    Design notes for this overlay
    
    
      
      
    • Placement: a full-window modal over the chat, not a side pane. Esc closes it. Tab cycles inside it, and focus returns to the trigger when it closes.
      • 
      
    • Chrome: Copy, Download, Open in app, History, and Quote in chat appear for every file. Find, zoom, paging, edit, and the source toggle appear only where they apply.
      • 
      
    • Edits: vault notes, personality.md, code, CSV, HTML source, and diagram source are editable. PDF and image files are not, and web captures are read-only as evidence. Save writes a new version. Older versions open read-only, and Restore writes a new version.
      • 
      
    • Risk handlers: a generated region shows a band and a revert-or-keep warning. personality.md asks “Approve this version for new tasks?” before a draft reaches new tasks. Existing tasks keep their bytes.
      • 
      
    • Trust: every header carries its taint. Quotes keep the source taint and go out as untrusted text unless the owner marks the message trusted.
