Design notes for this screen

  • Agent-to-agent threads follow 06-agents.md: one shared thread listed under both participants (⇄ icon, same ThreadId). The directions mock's “channels” are not used here.
  • Per-agent budgets in the rail are token meters only (12.4k / 30k tok) to match the budget contract. Dollar readouts from the directions mock are not accepted yet.
  • File chips encode source and optional location (p.3). The hover card shows source badge, type, size, provenance, and a text snippet. Click opens the full-screen overlay (task 3); Ctrl+Click opens the desktop app.
  • Attachment cards sit above the human message; queued composer attachments show as removable chips.
  • NeedsHuman flips the header pill to the warning token, shows the banner under the header, disables the composer, and keeps both Stop controls reachable.
  • Status is always shape + text: filled dot Running, hollow dot Sleeping, diamond Needs you.
