Super Agent IA

  • Five sidebar sections, in order: Needs you (waiting for you, blocked, failed), Working (queued, running), Completed, Pinned, and Archive (collapsed, count only). A pinned row lives only in Pinned and keeps its phase text.
  • Helpers are never top-level. They appear only under their parent task, with their own phase text.
  • Read-only detail. A row opens detail: transcript, tool events, artifacts, attempts, criteria, and helpers. Detail actions only insert a parent or helper reference into the Router composer. Nothing sends, runs, or changes phase from detail.
  • One conversation. The center pane is the single Router transcript with one composer. Stop all running threads is the only global stop, and it is quiet. Waiver and approval decisions are host controls on the banner, not chat text.

Design notes for this screen

  • Sections follow 14-super-agent-router.md: Needs you, Working, Completed, Pinned, Archive. Helpers sit under their parent, never in the top list.
  • Waiver is an owner decision on the host banner (Accept waiver or Keep open). Replies in the Router chat do not waive a criterion. The row phase reads “Blocked”, and its summary names the waiver.
  • Detail is read only. Insert reference only adds text to the composer. It does not send, run a step, or change phase.
  • Controls: Stop all running threads is the only global stop, and it is quiet. Per-task Stop lives only on the approval banner and sheet, never in rows or detail.
  • Settings replaces the Router pane from the rail footer. Model connection is first; the API key is write-only and shows as dots when set. Saving affects future calls only.
  • Status is always shape + text: diamond Needs you, filled dot Running, filled square Completed, hollow square Archive.
