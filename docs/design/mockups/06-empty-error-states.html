What this mock settles, and what to check

  • Empty states use the 09 copy. No tasks, Model connection not configured, Cache without facts, and Brain without facts each say what exists and what to do next. None implies history that does not exist.
  • Router failure keeps the draft (FP-ERR-01). Retry resends the same draft; a failed retry keeps it too. The copy names the model connection, not a provider.
  • Model connection not configured disables the composer and offers Open Settings. The key is never shown, and nothing is sent until the connection is saved.
  • The phone never implies the desktop's work moved. The unreachable state names the last update and the address tried. Uploads are not queued (FP-CMP-05).
  • Stop all running threads is disabled on the phone while the desktop is unreachable, and the copy says where to stop them (FP-ERR-03). This is the gap recorded as OD-2 in 12. It needs an owner decision before the invariant in 09 can read as unconditional.
  • A failed preview gets one retry, then stays failed with the file unchanged and Download offered (FP-ERR-04).
  • Installers and executables get Download only. Open in app is never offered for them (FP-PRV-06). This refines the 03 chrome.
  • A too-large file shows a labelled partial preview and its cap, never a silent truncation (FP-ERR-06, limits in 12). The caps are proposals for owner confirmation.
