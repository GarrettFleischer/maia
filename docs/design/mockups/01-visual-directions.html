Maia Visual Directions

Maia: four visual directions

Each direction is a 1440 × 820 desktop screen: agent rail, a Scout thread waiting on approval, and the inspector. Direction 4 combines the strongest parts of the first three. Use the Dark / Light switch on each, click the Cache, Brain and Trace tabs, and drag the turn scrubber. The palette hex values below are the same values the mocks use. Fonts are system stacks (no downloads): Segoe UI Variable for the interface, Cascadia Mono for data, and Georgia where a direction sets the transcript in serif.

Agents talk to each other through tool calls that appear as collapsed lines inside your conversation, so there are no separate agent-to-agent threads. Channels put several agents in one room: click # build-crew in the rail to see one, and use the To control in the composer to address one agent or everyone at once.

Build on direction 4, Mint Ledger

It keeps what you liked in Night Mint: the mint accent, the dense monospace inspector, per-agent budgets in the rail and counts on the tabs. It adds Graphite Signal's clean split between accent and warning, its rounded controls, its tinted selection and its transcript type, which was the easiest to read. From Ink and Amber it keeps the warm-tinted light theme and the ruled ledger tables in the inspector. In every direction your messages now sit right-aligned in a filled block, and each agent's messages run flush left under its avatar and name, so who said what is clear at a glance.

Mint is used only for running, selection and primary actions, and orange only for the approval banner and its pill, so a NeedsHuman state cannot be mistaken for an active agent. Everything uses system fonts, so Windows and the Android PWA look the same.
