  • Any owner client: create, widen, or revoke grants; revoke secret labels; unpair a device; approve or deny requests.

What this mock settles, and what to check

  • Graph follows the spec rules. Radius tracks activation, dashed rings mark Untrusted facts, the accent path marks nodes walked this turn, and cold nodes stay in the keyboard list.
  • One selection across tabs. A fact picked in the graph, the list, a Trace range, or a Trace row selects the same FactId everywhere on the desktop.
  • Trace labels are text. full, half, rejected, and correction appear beside each range. Opaque reasoning signatures are never shown.
  • Dream proposals are Confirm. Accept and Reject are the only actions, and each is recorded once.
  • NeedsHuman copy comes from the kind. Only CapabilityApproval offers Approve on the phone; the other kinds show the phone line from the table.
  • Settings is the remote view. Admin fields are read-only and say “Change this on the desktop.”
