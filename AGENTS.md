# AGENTS.md

## Cursor Cloud specific instructions

### Project overview

**maia** is a Next.js 16 application (App Router, React 19, Tailwind CSS v4, TypeScript 5). It uses **Bun** as its package manager (`bun.lock`).

### Running services

- **Dev server**: `bun run dev` — starts Next.js on port 3000 with hot reload.

### Lint & Typecheck

- **Lint**: `bun run lint` (runs ESLint). Pre-existing errors exist in `types/routes.d.ts` and `types/validator.ts` — these are auto-generated by Next.js and should be ignored.
- **Typecheck**: `bunx tsc --noEmit`. Pre-existing errors in `types/validator.ts` about module resolution are expected for auto-generated Next.js types. Never pipe or redirect this command's output.

### Standard commands

See `package.json` `scripts` for `dev`, `build`, `start`, `lint`.

### Gotchas

- Bun must be installed before running any commands. The update script handles `bun install` but assumes Bun is available on `PATH` (installed to `~/.bun/bin/bun`).
- No test framework is configured yet. There is no `test` script in `package.json`.
- The `types/` directory contains auto-generated Next.js files — do not edit them manually.
- Per user rules: never run `supabase migrate`, never run builds unless asked, never use the `any` TypeScript type, treat lint warnings during build as critical errors.
